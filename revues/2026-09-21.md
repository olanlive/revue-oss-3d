# Revue OSS 3D — semaine du 15–21 sept. 2026

## Hardcraft 0.9.0-alpha

Add-on Blender 5.0+ qui retopo des exports CAD (STEP / Plasticity / OBJ) en patches quads/tris. La 0.9.0 (20 sept) ajoute le loft RAILS pour cylindres/cônes, plus de topo STEP, et des binaires converter Linux + macOS. Alpha GPL.

https://github.com/polozad/hardcraft-dist/releases/tag/v0.9.0-alpha

## B Hair ShapeKey 1.0.0

Première extension officielle pour de vrais shape keys sur les Hair Curves modernes (sculpt Curves, drivers, miroir). Blender 5.2 LTS+, GPL, extensions.blender.org (13 sept).

https://extensions.blender.org/add-ons/b-hair-shapekey/

## DV Skin Tools

Sortie initiale (14 sept). Weight paint / skinning style Maya (smooth multi-influences, mirror, copy weights, viz, undo, export JSON + script Maya). Blender 4.2+ / 5.x, GPL.

https://blenderartists.org/t/released-dv-skin-tools-powerful-weight-paint-tools-for-blender/1652741

## EXR Converter 0.10.0 / 0.10.1 (Derek Rein)

Desktop+CLI MIT pour EXR↔vidéo avec OCIO (ACES), slate/burn-in, ProRes. 0.10.0 corrige le bake ACES 2.0 + decode BRAW optionnel ; 0.10.1 durcit les browsers R3D/BRAW/ARRIRAW.

https://github.com/derek-rein/exr-converter/releases
