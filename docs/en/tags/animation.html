In-Place Animation Tool 1.0.1

GPL Blender extension that turns root-motion animations (Mixamo, Cascadeur, mocap, Rigify) into in-place cycles without feet sinking, keeping jumps and sway, and can extract a root bone for game engines. v1.0.1 on Oct 19, 2026.

B-Bone Gizmos 1.0.0

GPL Blender extension by Tal Hershkovich, extracted from AnimToolbox: a Pose Mode gizmo tool to shape bendy bones like Bézier handles (location, rotation, scale). Cited at the Oct 15, 2026 Animation & Rigging meeting as a reference for a native version.

Found via: Web — devtalk.blender.org (Oct 15 Animation & Rigging module meeting)

October 16, 2026

Dolly Zoom 1.0.0

GPL Blender add-on (4.2+): a dolly zoom (Hitchcock effect) slider for the viewport and the camera — focal length and movement linked, pivoting on the 3D cursor. First version, 1.0.0, released on Oct 11, 2026.

Found via: Web — extensions.blender.org (new)

October 15, 2026

Motion2MixamoRig (Blender extension)

Free tool (Apache-2.0) that copies the motion of a filmed person onto a Mixamo-rigged character and outputs a skinned GLB. An experimental Blender 4.2+ extension runs the pipeline from Blender. Featured on X on Oct 13.

Found via: X feed — @Stefan_3D_AI
