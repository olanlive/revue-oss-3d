Hardcraft 0.10.0-alpha

CAD retopology add-on for Blender (Plasticity/STEP/OBJ). 0.10.0-alpha (Oct 14) adds De-feature (pockets/bosses), cappers built into the topology (curved faces included), curve Join and selection by CAD continuity.

Preview Quads 1.0.0

Blender add-on that previews live, without touching the mesh, the triangles-to-quads conversion (same algorithm as Blender) with all its settings, then applies it in one click. Handy after a CAD import or booleans. Released on Oct 12.

UVgami 2.2.0

Automatic UV unwrapping add-on for Blender combining three engines: OptCuts, PartUV (GPU, SIGGRAPH Asia 2025) and xatlas. 2.2.0 (October 6) adds web unwrapping and a desktop app, updated to 0.3.0 on October 12, 2026.

Free add-on that redraws an edge loop along an editable spline, with X mirror, axis constraints and a Quick button to smooth in one go. 1.0.4 adds the industry compatible keymap.
