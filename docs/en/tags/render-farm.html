RenderMesh 0.3.0

Serverless Blender render farm for Windows PCs on a local network (C++, Apache 2.0): idle machines pick up batches of Eevee or Cycles frames, the project is transferred and outputs are brought back. JSON CLI included. v0.3.0 on Oct 16, 2026.
