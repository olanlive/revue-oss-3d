Blender 5.3 — Gaussian Splats natifs (alpha)

Les 3D Gaussian Splats entrent dans le cœur de Blender (plus d’add-on) : import PLY / SPZ, schéma USD UsdVolParticleField3DGaussianSplat, nœuds Geometry Nodes (Import SPZ, Set Point Cloud Type), rendu Workbench / EEVEE / Cycles. Alpha 5.3 (finale prévue ~10 nov 2026) ; pas d’export encore ; perfs / couleur / Apply Transform encore limités.

#emerging#usd

Light It Up 4.0.0

Add-on GPL gratuit (extensions.blender.org) : 17 presets d’éclairage studio éditables (lights natifs + empty), contrôles master absolus (intensité, température, key/fill, orbit), Fit To Subject, presets perso. La 4.0.0 corrige le collapse du rig à l’origine au 2ᵉ preset, la taille nulle des assets liés/instancés, et le basculement du rig sur personnages FBX.

#blender-addon

Blender 5.3 — bascule OCIO runtime

Mécanisme core pour changer la config OpenColorIO active à l’exécution (base pour des configs OCIO par projet). Fondations pipeline pour studios multi-configs ACES/OCIO ; l’UI projet complète n’est pas encore là.
