NodeForge 0.50.0

Add-on GPL qui compile un DSL Python-like en Geometry Nodes natifs (variables, opérateurs, packages). La 0.50.0 (18 sept) ouvre le projet en free software + package Math ; poussée encore active le 24 sept. Utile pour GN complexes maintenables / générables.

#blender-addon#emerging

Simple Deform Helper 2.7.58 (V2)

Extension GPL (extensions.blender.org) : rebuild Geometry Nodes avec cages Standard / Shear / FFD / Curve, chaînes, multi-objets, keyframe + bake. Blender 5.0+. Gros saut UX pour déformer/animer sans se battre avec le Simple Deform natif.

#blender-addon

Blenderbase 1.3.2

App desktop gratuite (Win/macOS/Linux), code source public : gérer versions Blender, add-ons/extensions et .blend. La 1.3.x (21 sept) ajoute Sync (réseau local, code chiffré, dossier cloud, fichier .bbsetup) pour cloner prefs/thème/keymap/add-ons entre machines. Signet X « Blender ».

#pipeline#emerging

Fusion → Blender Bridge

Paire d’add-ons GPL (Fusion 360 + Blender 4.2+) : sync géométrie en un clic via WebSocket local ; matériaux, modifiers, sharp edges et light links Blender survivent aux révisions CAD. Pas d’import Appearance Fusion (volontaire).

#blender-addon#cad-retopo#pipeline

Grease Pencil — Attribute Shape Keys (WIP)

Shape keys attributaires pour Grease Pencil en cours (PR #162946, prototype déjà jouable). Démos récentes (ex. rig 2D + drivers) : expressions faciales / morphs stroke sur builds expérimentales — pas encore dans une release stable.
