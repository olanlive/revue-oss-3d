Cloth Lab 0.8.1

Add-on GPL (slohero) pour cloth / vêtements dans Blender : presets tissu, pins/grabs, collisions, patrons, sewing, plis, finishing, et tearing dynamique expérimental (Blender 5.2+). La 0.8.1 (annonce 26 sept) sort une UI anglaise + source ; alternative libre aux workflows type Simply Cloth Studio.

#blender-addon#sim#emerging

Hair Bone Generator 1.2.0

Extension GPL (extensions.blender.org) : génère une chaîne de bones deform le long d’un brin de cheveux mesh (cartes, tubes, tresses). La 1.2.0 (22 sept) accélère les meshes denses et ajoute Mirror to Other Side (symétrie L/R). Blender 4.5+.

#blender-addon#hair#skinning

MattRM2 VFX Build 1.1

Build Windows non officiel de Blender 5.2 (GPL, sources jointes) orienté VFX : Deep EXR réel depuis Cycles (volumes éclairés, surfaces émissives/transparentes), Z Depth volume-aware, overrides par view layer (chemin + plage), export caméra Alembic corrigé (film back), nœud Curves Lofting. Portable, Win64 seulement.

#exr#pipeline#alembic#emerging

three-gpu-pathtracer 0.0.25 — WebGPUPathTracer

Path tracer WebGPU pour three.js (MIT) : la 0.0.25 (28 sept) expose WebGPUPathTracer via « three-gpu-pathtracer/webgpu », déprécie WebGLPathTracer ; 0.0.26 (29 sept) corrige le chargement CDN. Utile pour previews web path-tracés / intégration web 3D.

#emerging

CoatLink 0.2.0

Pont GPL Blender ↔ 3D-Coat (protocole AppLink) : sync modèles bidirectionnelle prévisible, sans baking ni chirurgie de scène. La 0.2.0 (24 sept) resserre le pont ; install one-click. Niche mais utile si 3D-Coat est dans le pipeline sculpt/retopo.

#blender-addon#pipeline#cad-retopo#emerging
