slatefree 1.2.0

Outil en ligne de commande en Rust (MIT, MayVortex ; Windows, macOS, Linux) pour synchroniser des centaines de clips multi-caméras sans clap ni timecode : l'audio continu d'un enregistreur (Zoom H4n etc.) sert d'horloge de référence, chaque clip y est recalé via son son interne, et on obtient une timeline FCP 7 XML pour DaVinci Resolve (une piste par caméra, l'enregistreur en bas) plus un CSV de contrôle par clip (statut ok / check / hors enregistreur, corrélation, dérive). On glisse le dossier de tournage sur slatefree.exe, ffmpeg à côté. Pensé pour mariages, conférences, events. Repo créé le 6 oct, déjà en v1.2.0.

Trouvé via : Fil X — @VFXDESK

7 octobre 2026

Render Animated .GIF 1.8.0

Extension Blender 4.2+ (GPL-3.0-or-later, byebyeLAN) qui exporte directement un GIF animé depuis le menu Render, sans outil externe (imageio-ffmpeg embarqué). La 1.8.0 (5 oct) sépare la qualité en mode Basic (presets Very Low à Very High) et Advanced, où l'on règle le dithering et la taille de palette. Le plus rapide passe par le VSE ; transparence possible via Film > Transparent (pas de semi-transparence en GIF).

Trouvé via : Fil X — @VFXDESK

5 octobre 2026

PostProject 0.6.0-alpha.1 (+ extension Blender VSE)

Couche d’identité média pour la post-prod (Apache-2.0, Rust + C ABI/C++/Python/CLI) : IDs d’assets stables, représentations (originaux, proxies, séquences d’images), provenance, relink déterministe par empreinte de contenu, production .pproj SQLite. 0.6.0-alpha.1 sortie le 4 oct. Pilotes OSS : extension Blender (GPL-3.0) « Find Missing Media by Content » pour le Sequencer, Kdenlive, Natron, OBS, Ardour, et validations OpenAssetIO / OpenTimelineIO.

ZeroGeometry Kit 1.0.1

Add-on Blender GPL : reframing vertical one-click (9:16 / 4:5 / 1:1) avec auto-follow, beat sync, loop doctor et wedge renders. Première release publique pour décliner une anim 16:9.

1 octobre 2026

CodeCinema

Framework MIT pour films « as code » : picture, musique, son, titres et master via un CLI (`codecinema run`). Config film.toml, toolkit audio partagé, assembly ffmpeg ; deux courts exemples (dont un duel 3D Blender 5.2+). Sortie initiale 30 sept–1er oct — piste émergente pour pipelines vidéo reproductibles / agents.

EXR Converter 0.10.0 / 0.10.1 (Derek Rein)

Desktop+CLI MIT pour EXR↔vidéo avec OCIO (ACES), slate/burn-in, ProRes. 0.10.0 corrige le bake ACES 2.0 + decode BRAW optionnel ; 0.10.1 durcit les browsers R3D/BRAW/ARRIRAW.
