image-blaster

Skillset MIT (Claude) image→monde 3D en ~5 min : meshes dynamiques (.glb/.obj), splat d’environnement (.spz), SFX ambiants. Orchestre World Labs Marble + FAL (Hunyuan 3D) + ElevenLabs — APIs payantes requises. Signal viral sur le fil X (3–4 oct) ; utile pour kickstart environnements / layout.

OpenDLSS-NR

Réimplémentation Vulkan MIT bit-exact du réseau Neural Rendering DLSS 5 (NVIDIA) — 71 blocs Swin/ViT, FP8, sans poids NVIDIA inclus. Port WebGPU navigateur fourni. Base OSS pour le neural rendering génératif.

three-dlss-nr 0.1.0

Port Three.js (TSL/WebGPU) d’OpenDLSS-NR : le réseau DLSS 5 NR en compute nodes, byte-identique à la référence. Démo live ; poids NVIDIA à fournir soi-même. Signal frais sur le fil X.

houdini-eevee-bridge 0.7.6

Pont Hydra MIT : EEVEE (worker Blender 5.2 headless) dans le viewport Solaris de Houdini — matériaux/lumières USD, UsdSkel, courbes/cheveux, holdouts, rendu final.
