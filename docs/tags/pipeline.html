MattRM2 VFX Build 1.1

Build Windows non officiel de Blender 5.2 (GPL, sources jointes) orienté VFX : Deep EXR réel depuis Cycles (volumes éclairés, surfaces émissives/transparentes), Z Depth volume-aware, overrides par view layer (chemin + plage), export caméra Alembic corrigé (film back), nœud Curves Lofting. Portable, Win64 seulement.

29 septembre 2026

CoatLink 0.2.0

Pont GPL Blender ↔ 3D-Coat (protocole AppLink) : sync modèles bidirectionnelle prévisible, sans baking ni chirurgie de scène. La 0.2.0 (24 sept) resserre le pont ; install one-click. Niche mais utile si 3D-Coat est dans le pipeline sculpt/retopo.

#blender-addon#pipeline#cad-retopo#emerging

27 septembre 2026

Blenderbase 1.3.2

App desktop gratuite (Win/macOS/Linux), code source public : gérer versions Blender, add-ons/extensions et .blend. La 1.3.x (21 sept) ajoute Sync (réseau local, code chiffré, dossier cloud, fichier .bbsetup) pour cloner prefs/thème/keymap/add-ons entre machines. Signet X « Blender ».

27 septembre 2026

Fusion → Blender Bridge

Paire d’add-ons GPL (Fusion 360 + Blender 4.2+) : sync géométrie en un clic via WebSocket local ; matériaux, modifiers, sharp edges et light links Blender survivent aux révisions CAD. Pas d’import Appearance Fusion (volontaire).

Blender 5.3 — bascule OCIO runtime

Mécanisme core pour changer la config OpenColorIO active à l’exécution (base pour des configs OCIO par projet). Fondations pipeline pour studios multi-configs ACES/OCIO ; l’UI projet complète n’est pas encore là.
