Mio3 Flex 1.0.4

Add-on Blender gratuit (GPL-3.0, mio3io) qui redessine une edge loop le long d'une spline éditable : points de contrôle à déplacer, densité ajustée au nombre de vertices, miroir X, contraintes d'axe et bouton Quick pour lisser d'un coup. Inspiré de MiraTools (implémentation indépendante). Disponible sur Blender Extensions (Blender 4.2+), 1.0.4 ajoute le keymap industry compatible.

Trouvé via : Signet X — @JanvandenHemel
