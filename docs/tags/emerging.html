Blenderbase 1.3.2

App desktop gratuite (Win/macOS/Linux), code source public : gérer versions Blender, add-ons/extensions et .blend. La 1.3.x (21 sept) ajoute Sync (réseau local, code chiffré, dossier cloud, fichier .bbsetup) pour cloner prefs/thème/keymap/add-ons entre machines. Signet X « Blender ».

Blender 5.3 — Gaussian Splats natifs (alpha)

Les 3D Gaussian Splats entrent dans le cœur de Blender (plus d’add-on) : import PLY / SPZ, schéma USD UsdVolParticleField3DGaussianSplat, nœuds Geometry Nodes (Import SPZ, Set Point Cloud Type), rendu Workbench / EEVEE / Cycles. Hardcraft 0.9.0-alpha

Add-on Blender 5.0+ qui retopo des exports CAD (STEP / Plasticity / OBJ) en patches quads/tris. La 0.9.0 (20 sept) ajoute le loft RAILS pour cylindres/cônes, plus de topo STEP, et des binaires converter Linux + macOS. Alpha GPL.
