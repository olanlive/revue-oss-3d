7 octobre 2026

Splat Slicer 0.2.9

Nouvelle extension Blender 5.3 (GPL-3.0, Tim Fennell, l'auteur de Gaussian Splat Patch) qui découpe un scan Gaussian splat importé nativement (PLY/SPZ) en couches à imprimer sur film transparent puis à empiler en bloc laminé. On définit la taille du bloc en mm, l'épaisseur film + colle, on prévisualise couche par couche dans le panneau N, puis export PDF (repères et traits de coupe) ou PNG, fichiers blanc pour impression DTF et volumes DICOM/NIfTI/NRRD, plus un aperçu optique Cycles. Repo créé le 5 oct, déjà en v0.2.9 (6 oct) ; l'auteur précise ne pas avoir encore testé l'impression réelle.

Trouvé via : Fil X — @VFXDESK

ROTONIX 2.0.0 beta 1

Assistant de matte IA pour Nuke 15+ (Bishal Pandit, code sous licence MIT ; les modèles gardent leurs propres licences), publié sur Nukepedia le 6 oct. Un seul panneau pour sélectionner le sujet (points +/−, bbox, peinture, gomme, plusieurs objets), tracker en avant/arrière avec preview live, retoucher, puis exporter la plage de travail en séquence alpha lisible par un Read. Par défaut SAM 2.1 Large pour la découpe, ViTMatte Base pour les bords, RAFT pour la stabilité temporelle. Tout tourne en local, rien n'est uploadé. Bêta gratuite Windows uniquement (GPU NVIDIA).

Trouvé via : Fil X — @VFXDESK

AOV Rebuild Pipeline

Plugin Python pour Nuke 14 à 17 (MIT, michaelpbb) qui reconstruit automatiquement la beauty à partir des AOV d'un EXR multicouche : détection auto du moteur (Arnold, Redshift, V-Ray, Karma, UE5), mode Basic (addition rapide) ou Advanced (raw × filter, direct/indirect séparés), arbre de nodes propre généré automatiquement, passes depth/motion vector préparées. QC intégré en deux niveaux : contrôle que toutes les couches sont là + audit pixel par pixel (Difference) contre la beauty d'origine. Repo créé le 5 oct.

Trouvé via : Fil X — @VFXDESK

7 octobre 2026

slatefree 1.2.0

Outil en ligne de commande en Rust (MIT, MayVortex ; Windows, macOS, Linux) pour synchroniser des centaines de clips multi-caméras sans clap ni timecode : l'audio continu d'un enregistreur (Zoom H4n etc.) sert d'horloge de référence, chaque clip y est recalé via son son interne, et on obtient une timeline FCP 7 XML pour DaVinci Resolve (une piste par caméra, l'enregistreur en bas) plus un CSV de contrôle par clip (statut ok / check / hors enregistreur, corrélation, dérive). On glisse le dossier de tournage sur slatefree.exe, ffmpeg à côté. Pensé pour mariages, conférences, events. Repo créé le 6 oct, déjà en v1.2.0.

Trouvé via : Fil X — @VFXDESK

Gaussian Splat Patch 0.1.12

Extension Blender 5.3+ (GPL-3.0, Tim Fennell) pour retoucher des scans Gaussian splat importés nativement (PLY/SPZ) : 7 brosses Erase, Select, Clone, Heal, Spot Heal, Bridge et Restore, avec feather, mode Surface/Through et Restore en guise d'undo sur les gros nuages. Nukomfy 0.1.1

Plugin Python pour Nuke 14.1+ (Apache-2.0, Francesco Lorussi) qui transforme des workflows ComfyUI en gizmos Nuke réutilisables : le TD configure le gizmo une fois, l'artiste règle quelques knobs dans sa comp, envoie le job à une machine ComfyUI du réseau, suit la progression dans un Render Manager et réimporte les frames. 0.1.1 (28 sept) corrige le mode non-GUI (rendus en ligne de commande / render farm) et le support de l'App Builder ComfyUI 0.29+. Companion côté serveur : ComfyUI-Nukomfy-Suite.
