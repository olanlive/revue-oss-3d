Blenderbase 1.4.0

App desktop gratuite (Win/macOS/Linux), code source public : gérer versions Blender et add-ons. La 1.4.0 (30 sept) permet d’appliquer un add-on à une autre version installée (drag & drop ou clic droit Apply to), avec copie/symlink dans le dossier de série et confirmation avant remplacement — utile pour cloner un set d’extensions entre 4.x / 5.x.

OpenUSDConnect

Live-link OpenUSD Apache-2.0 entre DCC / outils USD / services headless : transactions ordonnées (SQLite), replay à la reconnexion, transforms/géométrie/primvars/caméras/lumières/animation, MaterialX, layers partagés. Intégrations de référence Blender, usdview, Unreal, MCP et Python ; commits actifs fin septembre (cible OpenUSD 26.08). Priorité pipeline USD multi-app.

BlenderShelf 0.2.2

Add-on GPL-3.0 : étagère flottante de boutons custom dans le viewport 3D + pie menu contextuel (style shelf Maya). Projet né fin septembre ; la 0.2.x (30 sept) ajoute des shelves par mode (Object/Edit/Sculpt/UV/Shader/GN), icônes UV/sculpt, et stocke le placement des labels par layout horizontal/vertical. Blender 4.2+ / 5.x.

CodeCinema

Framework MIT pour films « as code » : picture, musique, son, titres et master via un CLI (`codecinema run`). Config film.toml, toolkit audio partagé, assembly ffmpeg ; deux courts exemples (dont un duel 3D Blender 5.2+). Sortie initiale 30 sept–1er oct — piste émergente pour pipelines vidéo reproductibles / agents.

Cloth Lab 0.8.1

Add-on GPL (slohero) pour cloth / vêtements dans Blender : presets tissu, pins/grabs, collisions, patrons, sewing, plis, finishing, et tearing dynamique expérimental (Blender 5.2+). La 0.8.1 (annonce 26 sept) sort une UI anglaise + source ; alternative libre aux workflows type Simply Cloth Studio.

MattRM2 VFX Build 1.1

Build Windows non officiel de Blender 5.2 (GPL, sources jointes) orienté VFX : Deep EXR réel depuis Cycles (volumes éclairés, surfaces émissives/transparentes), Z Depth volume-aware, overrides par view layer (chemin + plage), export caméra Alembic corrigé (film back), nœud Curves Lofting. Portable, Win64 seulement.
